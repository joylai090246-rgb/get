免費上線指南

如何將本網站用 GitHub Pages 發佈？

只需按照以下 5 個步驟，就能將這份完全使用 HTML/CSS/JS 撰寫的網頁免費部署到 GitHub Pages，展示給全世界看！

1

創立 GitHub Repository 儲存庫

登入 GitHub，點擊右上角「+」選擇「New repository」，命名為 university-portfolio。

2

將本原始碼存為 index.html

在你的電腦本機資料夾中建立名為 index.html 的檔案，並將此網頁完整代碼貼上儲存。

3

推動 (Push) 代碼至 GitHub

開啓 Terminal 或 Git Bash，依序執行以下指令：

git init
git add .
git commit -m "feat: 大學四年作品集首次發佈"
git branch -M main
git remote add origin https://github.com/你的帳號/university-portfolio.git
git push -u origin main
4

開啟 GitHub Pages 設定

進入該 Repo 的 Settings ➔ 點選左側 Pages ➔ 將 Source 設定為 Deploy from a branch，Branch 選擇 main 後按下 Save。

5

完成！獲得你的個人品牌網址

等待約 1-2 分鐘，你的網站就會在 https://你的帳號.github.io/university-portfolio/ 正式上線！
